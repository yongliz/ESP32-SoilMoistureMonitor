## 1 项目概述

本项目实现一套基于ESP32的花卉土壤湿度监控系统，实现土壤湿度采集、本地显示、微信远程告警推送、HomeAssistant智能家居接入(暂不实现)；适配家庭盆栽养护场景。
解决痛点：依靠经验浇水、无法远程知晓盆土干湿、忘记浇水导致花卉枯死；实现本地可视化、远程消息提醒、智能家居联动。

## 2 系统总体架构

系统分为五层：

1. **采集层**：ESP32主控 + 电容式土壤湿度传感器，采集土壤模拟ADC信号；
2. **本地交互层**：EPD213R 2.13 寸红黑白三色水墨屏驱动，本地显示湿度、设备状态、告警信息、采样时间；
3. **网络层**：WiFi网络，支持HTTP请求、MQTT协议、网络时间同步；
4. **消息推送层**：Server酱服务实现微信消息推送；
5. **智能家居平台层**：HomeAssistant，接收MQTT湿度数据、存储历史曲线、自动化通知。

运行模式：

- 模式：电池低功耗模式：大部分时间深度睡眠，定时唤醒完成采集‑联网‑上报‑推送，之后重新休眠。

## 3 硬件需求

### 3.1 硬件清单

|器件|规格|用途|
|---|---|---|
|ESP32开发板|ESP32‑WROOM32 / ESP32‑S3|主控单元|
|土壤湿度传感器|FC‑28电容式|采集土壤湿度，禁止电阻式（易腐蚀）|
|水墨屏显示屏|EPD213R 2.13红黑白三色水墨屏 分辨率 212×104，SPI 接口|本地数据显示（插电版使用）|
|锂电池套件|18650 + TP4056充放电模块|电池低功耗版本供电|
|杜邦线|若干|硬件连接|

### 3.2 硬件引脚定义

1. 电容土壤湿度传感器

- VCC → 3.3V
- GND → GND
- AO模拟输出 → GPIO34（ADC1输入引脚）

> ⚠️禁止5V供电；AO引脚对地并联104瓷片电容，抑制数值跳变。

1. 水墨屏显示屏 EPD213R SPI接口

- 硬件引脚定义：
  - SCK → GPIO18
  - MISO → GPIO19
  - MOSI → GPIO23
  - CS → GPIO22 （选空闲电平低）
  - RST → GPIO21 （选空闲电平低）
  - DC → GPIO20 （选空闲电平低）  
  - VCC → 3.3V
  - GND → GND

1. 电池套件

- VCC → 3.3V
- GND → GND
- VBAT → GPIO35（模拟输入引脚）

## 4 功能需求

### 4.1 数据采集功能

1. 周期性读取土壤ADC原始值；
2. 使用用户校准参数（干土ADC、泡水ADC）映射换算为**0‑100%土壤湿度百分比**；
3. 对湿度数值做边界约束，限制在0‑100%；
4. 参数可配置：采集周期、浇水告警阈值、告警回差；
5. 串口输出调试信息：ADC原始值、湿度百分比，方便校准调试。

>校准参数说明：
>adcDry：探头置于空气中完全干燥时ADC读数；
>adcWet：探头完全浸泡水中ADC读数；
>dryThreshold：干旱告警阈值（%）；
>回差：阈值+10%，用于清除告警锁，防止临界值反复报警。

### 4.2 水墨屏显示屏本地显示功能

1. 开机显示WiFi连接状态、设备IP；
2. 主界面展示：项目名称、当前湿度百分比、土壤状态（正常/需要浇水）；
3. 展示网络状态：WiFi、MQTT连接状态；
4. 采样方案：每2小时采集一次，刷新显示，**同一状态持续4小时**。每次采样采取多次采样平均值，避免随机误差。
5. 展示当前采样时间，格式：YYYY-MM-DD HH:MM:SS。
6. 展示当前土壤湿度百分比，格式：XX%。
7. 展示当前状态：正常/需要浇水。
8. 展示当前告警状态：正常/告警。
9. 电池低功耗模式下，展示当前电池电压，格式：XX.XXV。

### 4.3 Server酱微信推送功能（可暂不实现）

1. 支持两种推送：异常告警推送、定时状态上报；
2. 土壤湿度低于告警阈值，发送微信浇水提醒，**同一干旱状态仅推送一次**；
3. 湿度回升超过阈值+回差，解锁告警标记，允许下次告警；
4. HTTP请求中文自动URL编码，避免消息乱码；
5. WiFi断开情况下跳过推送，不产生无效网络请求；
6. 可配置关闭推送（SendKey置空字符串）。

推送消息示例：

- 告警标题：⚠️花卉浇水提醒；内容：当前土壤湿度XX%，土壤偏干，请及时浇水；
- 定时上报标题：🌷花卉土壤湿度报告；内容：湿度XX%，浇水阈值XX%。

### 4.4 HomeAssistant MQTT接入功能（可暂不实现）

1. ESP32唤醒/周期上报湿度数据至MQTT；
2. 支持HA MQTT自动发现，无需手动编辑YAML配置；
3. 上报实体信息：名称、唯一ID、单位%、设备类别humidity、设备图标；
4. HA自动保存历史数据，生成湿度变化曲线；
5. HA端支持配置自动化：湿度低于阈值推送手机APP通知；
6. 通过Xiaomi MIoT集成对接米家，实现小爱同学语音查询土壤湿度。

>电池休眠模式特性：ESP32大部分时间离线，HA实体会短暂显示不可用，属于正常现象。

### 4.5 深度睡眠低功耗功能

1. RTC定时器定时唤醒，可配置唤醒间隔；
2. 唤醒完整流程：采集湿度 → 连接WiFi → MQTT上报HA → 可选微信推送 →断开网络 →进入深度睡眠；
3. RTC_DATA_ATTR保存告警标记，深度睡眠不丢失告警状态，防止重复推送告警；
4. 休眠期间CPU、WiFi全部关闭，实现微安级功耗；
5. WiFi联网失败直接进入睡眠，不阻塞流程。

### 4.6 参数配置能力

所有业务参数集中代码头部配置区，无需修改业务逻辑：

- WiFi账号密码；
- Server酱 SendKey；
- MQTT服务器地址、账号密码；
- 采集周期、休眠唤醒时间；
- 土壤告警阈值dryThreshold；
- 传感器校准adcDry、adcWet。

## 5 非功能需求

### 5.1 稳定性

1. WiFi连接失败有超时处理，不死机；
2. MQTT连接失败重试，失败直接跳过上报；
3. 网络异常不阻塞主流程；
4. 传感器采集做简单抗跳变处理。

### 5.2 约束限制

1. Server酱免费版限制：每分钟最多5条，每日最多100条；推送间隔不小于30分钟；ESP32设备需要外网访问能力；
2. MQTT通信需要局域网内部署Mosquitto Broker；
3. 电池版续航参考：18650‑2500mAh，30分钟唤醒一次，续航2‑4周；传感器电源受控断电可提升续航。

### 5.3 易用性

1. 参数全部集中配置区，修改简单；
2. 串口输出调试信息，方便故障定位；
3. 硬件接线简单，元器件为通用模块。

### 5.4 可扩展性

1. 预留扩展：可增加光照传感器、水泵自动浇水；
2. 推送可替换为企业微信机器人；
3. MQTT标准协议，可对接其他智能家居平台。

## 6 业务逻辑规则

1. 湿度 < dryThreshold：触发浇水告警，只推送一次，告警标记置位；
2. 湿度 > dryThreshold +10：清除告警标记，允许下次告警；
3. 定时周期执行采集，上报HA；插电版支持定时微信上报；
4. 电池版每次唤醒完成一次采集上报，完成直接休眠；
5. WiFi失败场景：跳过推送、跳过MQTT上报。

## 7 风险与注意事项

1. 传感器必须做干土、湿土ADC校准，否则湿度百分比不准；
2. 电容传感器必须3.3V供电，严禁接5V；
3. Server酱密钥不可泄露；
4. 深度睡眠模式GPIO常接传感器会存在漏电，长续航建议GPIO控制传感器电源；
5. HA休眠状态实体不可用为正常现象。
