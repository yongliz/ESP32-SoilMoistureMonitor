# 硬件接线说明

目标板：**ESP32-S3**（PlatformIO `esp32-s3-devkitc-1`）

## 电容土壤湿度传感器（FC-28，3.3V）
| 传感器 | ESP32-S3 |
|---|---|
| VCC | 3.3V（严禁 5V） |
| GND | GND |
| AO | GPIO1（ADC1_CH0） |

- AO 与 GND 之间并联一个 104(100nF) 瓷片电容，抑制数值跳变。

## 水墨屏 SES2213JS0E1 / DEPG0213RWS800F41（2.13 寸红黑白三色，UC8151D 协议，SPI）
| 屏 | ESP32-S3 |
|---|---|
| SCK | GPIO12 |
| MOSI | GPIO11 |
| CS | GPIO10 |
| DC | GPIO13 |
| RST | GPIO14 |
| BUSY | GPIO15 |
| VCC | 3.3V |
| GND | GND |

- 屏为**写-only**，无 MISO 接线；DC 复用 GPIO13（S3 FSPI 默认 MISO 位置，被 DC 输出覆盖）。
- BUSY 低电平有效（0 = 忙）。

## 电池（18650 + TP4056 分压）
- 电池正极经分压后接 ESP32-S3：
  - 分压电阻：100k 接电池正极 + 100k 接 GND，中点接 **GPIO2（ADC1_CH1）**。
  - 分压比 2:1，4.2V 满电时中点约 2.1V，在 `ADC_11db` 量程内。
